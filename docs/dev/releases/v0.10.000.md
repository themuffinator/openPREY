# openQ4 0.10.000

## Highlights

- **Competitive matches can now be run from one coherent Match Control
  surface.** Players ready and vote, captains manage their side, coaches and
  broadcasters receive filtered observer views, referees handle exceptional
  match actions, and local operators configure rules and series without giving
  those roles general server administration. Tactical timeouts, technical
  pauses, roster substitutions, self-only coach/substitute withdrawal, Duel
  queues and exact denial reasons all use the same server-authoritative
  operation path.
- **Best-of series now survive map changes and leave useful evidence.** BO1,
  BO3 and BO5 setup validates installed map pools and deterministic vetoes,
  advances only the selected map, restores the series and report draft from
  one digest-protected atomic checkpoint, and links each map's bounded JSON
  plus recorded server-side multi-view demo into a final series report.
- **Single-player save slots are harder to lose or load incorrectly.** New
  version 3 saves protect the complete save payload and footer with a checksum,
  recover interrupted slot replacement, and reject invalid format, ABI, or map
  data before the current map is torn down.
- **A new Arena Campaign joins single-player.** Choose **Arena** after selecting
  **Single Player** to fight through five escalating tiers and twenty curated
  matches, while **Mission** continues to open the original Quake 4 story.
- **Single-player menus now feel like one suite.** The Single Player path
  cleanly hands off from the main menu into Mission or Arena, the Demo Library
  uses the same list-and-preview language as Load Game, and shared rails,
  panels, and controls make moving between those screens feel deliberate on
  both wide and tall displays.
- **Long names and translations stay readable.** Demo rows now preserve their
  columns while the selected item remains clearly identified below the list;
  Arena uses concise localized card labels, larger briefing space, and compact
  action controls so translated text remains clear at the menu's intended size.
- **Every tier has its own climb and boss.** Win the first three matches to
  reveal the boss fight, then defeat the boss to unlock the next tier. Wins are
  saved, completed matches remain replayable, and a separate reset action
  leaves Mission saves untouched.
- **The circuit is easier to read and safer to manage.** Tier briefings, a
  visual progress bar, effective bot-skill previews, stronger boss markers,
  explicit next/retry/replay actions, neutral draw results, and confirmation
  before resetting progress make each choice clear before it takes effect.
- **The full openQ4 bot cast enters the circuit.** Hand-picked opponents,
  distinct play styles, per-character skill variation, and a final duel with
  the Makron make the ladder grow from approachable rookie fights into an
  endgame challenge.
- **Multiplayer bots now coordinate around the match, the map, and each other.**
  In Standard CTF, One Flag, Arena CTF and Arena One Flag they divide returns,
  interceptions, escorts, attacks and base defence instead of chasing one flag
  as a pack. Freeze Tag rescuers spread across frozen teammates, while DeadZone
  teams react to artifacts, ownership and deadlocks. Routes repair around live
  obstructions and use ordinary walk-activated doors; combatants choose spacing
  for their weapon, pursue recent sightings, dodge from either side, lead and
  avoid projectiles with their real trajectories, and protect moving teammates
  from direct or splash fire. Batched bot joins also balance before the players'
  first spawn instead of placing every new opponent on one side.
- **Classic combat modes keep the ladder varied.** Duel, Deathmatch, Team
  Deathmatch, Red Rover, and Clan Arena rotate through free-for-all, team, and
  elimination rules instead of repeating one match format.
- **Every match now feels like an event.** Arena skips multiplayer ready-up and
  opens with a cinematic challenge entrance, then freezes the final battlefield
  for a depth-of-field victory orbit before flowing through a staged match
  report and a clearly animated ladder update.

## Upgrade Notes

- Replace the engine executable and both `game_sp` and `game_mp` modules
  together. This release advances the in-tree game-module API to version 43 so
  shutdown can complete safely after declaration teardown; older game modules
  are rejected, while supported API-42 multi-view demos remain readable.
- IPv4 multiplayer uses direct UDP. Legacy `net_socks*` settings remain visible
  for configuration compatibility, but they do not enable a supported SOCKS
  UDP relay.
- IPv6 server-list results require a master server that answers the extended,
  address-family tagged reply. The legacy master reply carries four-octet IPv4
  records with no family tag and cannot represent an IPv6 address, so IPv6
  servers are reached by direct connect, LAN scan, or a manually added server
  entry until such a master is deployed.
- A hostname with both `A` and `AAAA` records resolves to its IPv4 address when
  both families are enabled. Use the bracketed literal form to connect over
  IPv6, or set `net_enableIPv4 0`, which narrows name resolution to `AAAA`.
- Paths that translate between address families, such as NAT64, are not
  supported. Both ends size their message fragments from the address family
  they observe, so a translator leaves them disagreeing; such a path also
  exceeds the IPv6 minimum MTU in one direction. Native IPv4 and native IPv6
  are unaffected because both ends always observe the same family.
- A dual-stack server found by a LAN scan is listed once per address family,
  because its IPv4 and IPv6 endpoints are genuinely different addresses.
- Existing public and private servers remain casual unless an operator selects
  a `competitive_*` match profile. Legacy casual ready, team and vote behaviour
  is unchanged; managed matches use Match Control and reject inherited textual
  vote routes which could bypass typed validation.
- Competitive operators should review the
  [Competitive Matches guide](../../user/competitive-matches.md). Configure a
  protected `g_refPassword` before the session if remote referees are needed,
  and use a semicolon-delimited `si_mapCycle` when a series needs an explicit
  map pool. The referee credential is converted to a verifier and cleared when
  the session starts.
- Active series write schema-3 paired recovery beneath `fs_savepath` and maintain
  `g_matchSeriesRecoveryId` automatically. Team series restore their competition
  side mapping; after a recovered Duel, a trusted server operator must bind
  both current human connections with `matchSeriesBind a <slot>` and
  `matchSeriesBind b <slot>` rather than relying on a name or reused client
  slot. Dedicated operators can grant or revoke an eligible neutral observer
  with `matchBroadcaster <slot> <on|off>`.
- `g_matchEvidence` now defaults to `2` (full bounded journal plus final per-map
  JSON). Set it to `1` for final per-map JSON only or `0` to disable that
  optional artifact; an active series still keeps the minimum result journal
  required for its transactional final report.
- No extra maps or replacement assets are required. The Arena Campaign uses
  the official Quake 4 maps already required by openQ4 and does not depend on
  the optional community map pack.
- Existing Mission savegames and ordinary multiplayer settings are not reset.
  Arena progress is new in this release and begins at the first tier.
- Existing Mission save files are not deleted, but format eligibility is now
  strict. New saves use version 3 and load only on the exact same wire ABI; only
  six approved version 2 snapshots and same-build unstamped legacy saves remain
  eligible on Windows/MSVC x64. Unlisted, cross-OS or cross-architecture, and
  newer-format saves are rejected before map teardown, so retain a copy of
  important slots before upgrading.
- The experimental macOS packages target Apple Silicon/arm64. Intel Mac packages
  are not published or supported, and Rosetta is not a supported substitute.
- The `macos_graphics_bridge=metal` package remains a Metal bridge around the OpenGL renderer, not a native Metal renderer. `platform_backend=native` is
  comparison-only diagnostic infrastructure, not a release backend. Promotion
  remains tracked by issue #73 and the evidence in
  `docs/dev/macos-signoff-evidence.md`.
- If an Arena card reports a missing required map, verify the retail Quake 4
  files and content paths before installing loose map replacements.

## Change Log

- IPv6 multiplayer works end to end on Windows, Linux, and macOS. A server binds
  IPv4 and IPv6 on the same port, so one address serves every client; direct
  connections accept `[2001:db8::1]:27650` and scoped link-local literals; LAN
  scanning finds IPv6 servers through link-local multicast, which replaces the
  broadcast IPv6 does not have; addresses print in one canonical form on every
  platform, so the server browser and server-side ban lists agree; a client
  reaching a dual-stack server over IPv4 is recorded once rather than twice; and
  messages are fragmented to fit the smaller IPv6 minimum path MTU so a
  connection cannot stall waiting for a snapshot no router will deliver.
  `net_ip6`, `net_enableIPv4`, and `net_enableIPv6` select the interfaces and
  families, including IPv6-only hosting, and `netIPv6SelfTest` gives a headless
  health check.
- Hosting and joining IPv4 games is now more dependable across Windows, Linux,
  and macOS. Direct addresses and IPv4 hostnames resolve consistently, the full
  port range through `65535` works end to end, invalid endpoints fail safely,
  and oversized UDP traffic cannot corrupt the next packet. Direct connections
  made after normal menu or single-player startup no longer fail with a false
  data/decl mismatch when scalable fonts are enabled. Server operators can run
  `netIPv4SelfTest` for a headless loopback health check before opening a public
  server.
- Added the managed competitive-match framework and localized Match Control
  pages for status, teams/rosters, proposals, rules, series and evidence. Rules
  are validated and frozen transactionally; player, captain, coach,
  broadcaster and referee capability checks are connection scoped; readiness,
  joins, locks, queues, substitutions, tactical/technical pauses, force-ready,
  aborts and forfeits commit through revision-checked typed operations. Managed
  legacy votes now fail closed while casual compatibility remains. Recipient
  views redact before serialization, every live camera-follow transition is
  reauthorized, and ordinary spectators cannot bypass protected live POVs
  through roster invitations. Managed matches authoritatively track supported
  placed, respawning major items on the pause-safe match clock and project their
  timers only to explicit broadcasters and referees; players, coaches and
  ordinary spectators receive none, and the UI never renders raw item tokens.
  Series add validated map pools, deterministic veto/side history, safe
  selected-map loading, authoritative result commits and atomic paired
  series/report recovery without persistent player identity. Final schema-v2
  per-map JSON evidence links series identity and the safe qpath of the server
  MVD, while the immutable schema-1 series report records ordered map outcomes,
  artifact status and available aggregates; incomplete `.mvd.part`
  output remains visibly distinct and any recording or write failure cannot
  change the winner. The broadcaster role and recorded server MVD are supported;
  live Q4TV/repeater transport, broadcast delay and live multi-POV are deferred,
  with only a fail-closed public projection boundary reserved for a future
  repeater adapter.
- Added whole-file save checksum/footer validation and a synced, recoverable
  description/preview/payload commit that records intentional preview deletion.
  Files above 512 MiB are rejected before checksum work; load now preflights
  compatibility and map availability before teardown, while bounded state and
  typed object/GUI references reject corrupt restores near the offending field.
  The Load Game preview frame now follows each selected image's native aspect
  ratio instead of stretching widescreen, classic 4:3, ultrawide, or portrait
  previews into the stock 4:3 box.
- Kept bordered windows fully reachable when they are created, moved between
  displays, resized, or restored after fullscreen. openQ4 now measures the
  native title bar and resize borders on Windows, X11, and macOS, saves the
  outer-frame position, and reserves that chrome when fitting a requested
  client size into a monitor's usable area. Native Wayland continues to let the
  compositor choose absolute placement.
- Improved stability for malformed console/configuration text and multiplayer
  downloads. Invalid quote, filter, numeric, and oversized impulse inputs now
  fail safely. Command arguments and escaped reconstructions stay within their
  slot/storage limits, token lookahead no longer consumes the next token, and
  extreme string growth is rejected before allocation arithmetic can wrap.
  Relative write/remove targets reject traversal, rooted paths,
  non-portable characters, and platform device aliases before touching the save
  directory. Server-offered files are restricted to new PK4 destinations beneath
  that directory, handle destination failures cleanly, and reject Windows device
  names, invalid or overflowing advertised sizes, and malformed response entries.
  Package transfers are capped to the size shown in the confirmation prompt and
  must arrive at exactly that size. Transfer sessions now release their resources
  on every success and failure path; servers also report predictable
  package availability when no game-code package is requested.
- Made standalone game-module builds more dependable. Changes in gameplay or
  shared engine support code now refresh the complete staged source snapshot by
  content, and legacy inline-assembly SIMD code is compiled only for its supported
  32-bit x86 target. This prevents stale modules while keeping x64 and modern
  platform builds portable.
- Made Windows x64 builds easier to trust. Engine and standalone game-module
  builds are warning-clean, native-width values cross legacy 32-bit interfaces
  through checked conversions, and the corrected warning classes now fail the
  build if they regress. Non-libdecor platforms no longer receive a misleading
  SDL configuration warning, and validation reliably builds the explicitly
  selected companion GameLibs repository.
- Made bindings easier to recognize in menus and during play. Settings rows now
  summarize keyboard, mouse, and controller bindings with labeled keycaps and
  neutral device graphics, while supported prompts follow the input device used
  most recently. Direction keys use compact arrow symbols, upright mouse graphics
  fill the bound physical button without ambiguous numbers, and the controller Back/View input has a localized
  label. The icons now use nearly the full text-line height with smoother rounded
  detail, while centered multiplayer prompts receive a larger treatment; the
  spectator HUD uses the same presentation for its follow controls. Escape,
  Start, and Back now cancel bind capture without erasing the action, while
  Backspace and Delete clear it deliberately.
- Added runtime map entity-string companions for mods and servers. A `.ent`
  now replaces the complete entity string, while `.entx` appends validated
  point entities without modifying or redistributing the original map.
- Added a localized Mission-or-Arena choice beneath the Single Player menu.
- Unified the Demo Library, Single Player selector, and Arena browser around
  Quake 4's stock menu rails, grid, framed panels, and action controls. Tiled
  full-bleed chrome now fills extra screen space without stretching the
  readable menu cards, with input-safe transitions between views and back to
  the main menu.
- Reframed Arena's reset, progress, and result dialogs around the familiar
  legacy confirmation silhouette while retaining their richer staged reveals
  and clearer campaign feedback.
- Polished final menu motion and hierarchy: active Demo filters remain visibly
  selected, the playback deck rises in from the lower rail, and Arena launch,
  result, and progression panels now close behind a composed black layer
  instead of exposing individual nested elements during their exit.
- Added five named tiers with four authored matches apiece, localized match
  briefings, map and rule summaries, roster previews, lock states, and
  completion feedback.
- Added deterministic campaign rosters using all sixteen character bots, with
  tier skill rising from 1 through 5 and small per-opponent offsets.
- Expanded general multiplayer bot intelligence with independent movement and
  combat intent, inventory- and path-aware pickup scoring with soft team
  reservations, goal hysteresis, progress-based recovery, full stock-and-
  expansion weapon choices, and team assignment that reserves pending slots in
  the correct gameplay instance.
- Made navigation react to the live map: selected graph edges are collision-
  checked and repaired around movers, ordinary unlocked walk-activated doors
  remain traversable while gated doors remain barriers, jumps and drops carry
  deliberate travel penalties, and a scaled lower-bound A* heuristic preserves
  cost-correct choices across cheap jump-pad and teleporter links. Roaming also
  retries alternate reachable destinations when one candidate becomes blocked.
- Made projectile combat account for the whole flight instead of only the aim
  ray. Bots use live projectile bounds and gravity over segmented sweeps, check
  moving teammates and their future splash exposure with world cover, and can
  recognize incoming explosive danger from a direct path, predicted world
  impact or slow/resting fuse. Lateral visibility samples also let them acquire
  a genuinely exposed shoulder without seeing through cover.
- Improved moment-to-moment decisions with weapon-aware engagement distance,
  bounded pursuit from a fading cached position and velocity, extra priority
  for enemies threatening a friendly objective carrier, and an opposite-side
  dodge when the first escape direction is unsafe. Escorts use nav-projected
  trailing formation lanes, and defenders hold a capture perimeter rather than
  standing on the objective.
- Added deterministic distance-aware roles for Standard CTF, One Flag, Arena
  CTF and Arena One Flag, including returners, carrier interceptors, escorts,
  attackers, defenders and ordered per-instance assault-point chains. Freeze
  Tag uniquely pairs rescuers with bodies and raises urgency as a team nears
  elimination; DeadZone uniquely distributes artifacts and adapts escort,
  intercept and zone-contest strength to ownership and deadlock state.
- Added persistent match wins, boss unlocks, next-tier unlocks, final campaign
  completion, replay support, and a separate Arena-only progress reset.
- Added a confirmation step for progress reset, recommended-action focus for
  keyboard and controller navigation, distinct retry and replay choices,
  explicit draw results, and clearer tier/progression context.
- Made Arena match startup and results dependable: switching between Mission
  and Arena is safe while the game mode reloads, authored bots join at their
  exact intended skill, Duel contenders enter before the countdown, final
  scores come from the authoritative match state, and the campaign result
  screen can no longer be displaced by the ordinary multiplayer summary.
- Added an Arena-only presentation flow: delayed challenge-card launch,
  automatic cinematic entrance without a ready prompt, frozen end-of-match
  tableau, collision-aware victor orbit with focused depth of field, staged
  post-match ledger, and animated match, progress, boss, and tier updates on
  return to the ladder.
- Arena's private-server rules are now transactional. Completing, retrying,
  cancelling, disconnecting, encountering a recoverable error, or quitting
  restores the player's previous multiplayer map, limits, and bot settings.
- Moved the final Makron duel to the previously unused official
  Stroggenomenon tournament arena, avoiding a repeated boss map and giving the
  campaign a distinct final battleground.
- Added a stock-only campaign manifest so maps, modes, limits, skills, and bot
  lineups can be validated without duplicating retail map content.

## Known Limitations

- Competitive Match Control, protocols and persistence have automated contract
  coverage, but the final interactive windowed role/input matrix, repeated
  pause-world matrix, multi-map recovery run and generated-MVD playback signoff
  are still pending. The HUD and scoreboard now show the same compact,
  recipient-scoped match context as Match Control. Captain invitations for
  neutral spectators deliberately remain fail-closed. Item timing is limited to
  supported placed, respawning major items and authorized broadcaster/referee
  views; its final live pickup, respawn and repeated-pause qualification is still
  pending. This release does not provide live Q4TV/repeater transport, delayed
  broadcast or live multi-POV.
- Save/load remains a single-player feature. Multiplayer and dedicated sessions
  cannot be saved, and current `raw1` saves are not transferable between
  operating systems, compiler ABIs, or x64 and arm64.
- The campaign currently focuses on combat-driven modes. Objective-aware bots
  are available in ordinary multiplayer for Standard CTF, One Flag, Arena CTF,
  Arena One Flag, Freeze Tag rescue and DeadZone, but campaign cards,
  progression, and result flow have not yet been authored for those modes.
- Attack & Defend, Overload, Harvester and Domination do not yet expose the
  complete authoritative runtime state and scoring rules needed for dependable
  objective choices. Bots intentionally fail closed to general combat, pickup
  and roaming behavior in those modes rather than pretending to play an
  objective they cannot score reliably.
