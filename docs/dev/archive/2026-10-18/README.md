# Planning archive — 18 October 2026

The [development roadmap](../../roadmap.md) is the single active plan.
This archive preserves 72 superseded planning/research documents and
the old root TODO. Historical progress, instructions and support claims must
be read against their recorded revision; they do not schedule current work.

Technical requirements explicitly adopted by the roadmap and UI register remain
in scope. No requirement, migration entry or acceptance state was removed or
accepted by this relocation. The release record, current specifications,
support policies, implementation references and evidence indexes stay outside
the archive because they continue to describe contracts and observed results.

Source revision: `49a2710cc17fff014a9c1d67f328f206f264f7bd`. [Relocation manifest](manifest.json)
binds each original Git object and relocated file with SHA-256, and maps it
to its owning roadmap section. Archived text has only an archive notice and
link/path repairs; original bytes remain recoverable from that Git revision.

Archive hashes use LF-normalized UTF-8 so Git CRLF conversion on Windows
does not invalidate the record on Linux or macOS.
